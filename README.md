# dsh-focus-mode · 任务域聚焦
> 适配 DeepSeek Harness 的领域约束插件，收拢模型注意力，抑制自发跨域、私自触发附属工具

## 概述
本插件为每个会话锁定一个任务域，将模型推理资源与上下文注意力收拢到当前主任务；
本域任务做得更严谨、更准确；减少自发拓展、无关联想、额外衍生动作。
插件分为两层管控：**定向语义引导注入 + 工具调用兜底判定**，不是底层权限沙箱，存在识别边界。

### 管控规则
1. **任务域锁定**：会话绑定选中任务域，约束模型禁止自动跨域
2. **附属动作管控**：限制模型私自调用外部能力（沙箱执行、文件读写、联网、下载、剪贴板、系统信息、批量子任务、递归子任务、自助追问、OCR、文档解析）
3. 优先级：**专注模式 > 附属动作确认 > 锁定模式 > 通用默认**
4. 四个独立开关互不覆盖：锁定模式、附属动作弹窗确认、专注模式、显示执行方式标记；状态栏实时标识，全部按会话持久化
5. 专注模式：沙箱禁用，仅支持手工列式计算；重型计算会先询问用户，禁止私自跑代码
6. 报错区分：沙箱权限失败、脚本错误、专注模式拦截分别给出友好提示，不抛出底层原始报错
7. 仅限制自动跨域、私自触发附属动作，**不削弱主任务算力倾斜与输出质量**
8. 文件读写同样归入附属动作，锁定模式下必须经过附属动作判定
9. 能力边界说明：剪贴板读取、部分隐蔽自动跨域在DSH框架无工具拦截入口，插件仅能做风险提示弹窗，无法强制阻断；词表已扩充，但仍存在漏识别、误识别可能
10. 专注模式自带三档严谨等级（默认【严谨精简】，会话持久化），档位仅控制复核深度、输出篇幅；沙箱禁用、附属管控规则不受档位影响

| 档位 | 行为 | 适用场景 |
|---|---|---|
| **快速核验** | 仅基础合规校验，无深度多轮复核、无多方法交叉验证；保留执行标记与误差提示 | 快速验算、核对；token 开销最低 |
| **严谨精简**（默认） | 自动识别任务体量：简单查询只给结论与算式；复杂测算启用完整复核流程 | 日常默认，平衡可信、篇幅与成本 |
| **极致严谨** | 强制完整校验：多方法异常检验、累计值排除、污染回归对比、置信区间、完整推理链 | 高风险、正式报告、对外交付；推理开销与篇幅最高 |

> 三档仅代表复核深度，不是安全档位；无论选择哪一档，专注模式的沙箱禁用、附属管控规则不变。
> 开启专注模式后，识别“简短输出、只要结论”类需求会压缩篇幅，但不会省略执行标记与误差提示。

> ⚠️ **能力边界（请先阅读）**
> 本插件是**语义层面意图约束 + 产物级兜底判定**，不是系统权限沙箱，无法做到100%精准识别。
> 仅能识别调用特征明确的工具；用通用工具隐蔽跨域，只能依靠引导词软性约束。
> 混合复杂需求，建议切回【通用模式】使用。

## 1. 七种任务域与附属白名单
| 模式 | 主域（算力优先投入） | 附属配套（仅用户明确要求时执行） |
|---|---|---|
| 通用默认模式 | 不限任务域 | 无限制 |
| 图片聚焦模式 | 识图、修图、生图 | 简短文字描述 |
| PPT 聚焦模式 | 大纲、页面文案、版式 | 页面备注 |
| 视频聚焦模式 | 脚本、分镜构思 | 配套台词 |
| 代码聚焦模式 | 编码、调试、排错、解读 | 绘制流程图、生成文件 |
| 文档审阅聚焦模式 | 精读、批注、摘要、对比 | 整理提纲 |
| 数据分析聚焦模式 | 计算、校验、数据处理 | 绘图、导出/运行脚本 |

每个模式的定向引导文本写在 `lib/modes.js` 的 guidance 字段，可自行审阅修改。
引导词后追加动作判定规则：主域直接执行、附属需要用户明确提出、跨域直接拦截。

## 2. 面板交互
- **常驻状态胶囊**：输入框左下角持续展示当前模式，锁定状态带高光圆环
- 点击胶囊展开面板（输入框上方）：
  - 标签平铺：7个模式标签横向排布；窄窗口自动收拢多余标签到【更多模式】下拉，选中模式永远可见，不换行溢出
  - 标签下方小字：当前模式主域+附属白名单简介
  - 锁定模式开关
  - 附属动作弹窗确认开关（默认关闭）
  - 重置为通用模式按钮
  - 拦截统计：`已拦截 N 次 · 附属放行 M 次`
- 所有标签、下拉项支持hover悬浮提示

## 3. 三类动作判定
| 动作类型 | 判定规则 | 结果 |
|---|---|---|
| ① 主域任务 | 调用属于当前模式主域 | **直接执行**，算力优先投入深度处理 |
| ② 附属配套动作 | 命中该模式附属能力 | 用户提问里明确写出需求才允许执行；AI中途自发触发附属动作直接拦截，不弹窗 |
| ③ 完全跨领域任务 | 属于其他领域 | **直接拦截，不提供临时放行** |

附属确认开关逻辑：
- 关闭（默认）：用户明确提出附属动作 → 直接执行
- 开启：用户明确提出附属动作 → 弹出确认框，选择【执行/跳过】
- 用户没有主动提出附属动作：无论开关状态，一律拦截

确认弹窗示例：
> 当前处于【数据分析聚焦模式】，检测到你在提问中要求的附属配套动作（绘图），是否执行本次附属动作？
> 选项：【执行】【跳过】

拦截后引导模型回到主任务，禁止绕道拆分、规避约束。

## 4. 兜底判定识别范围
`tools/pre-execute` 只识别特征明确的调用：
| 判据 | 归入领域 | 例子 |
|---|---|---|
| 工具名生成类 | 图片 / 视频 | `generate_image`、`stable_diffusion` |
| 产物扩展名 | PPT / 文档 / 数据 / 视频 / 图片 | 输出 `.pptx`、`.xlsx`、`.pdf` |
| 命令特征 | 数据分析 | 脚本内 `matplotlib` / `plotly` / `plt.` |

通用工具（读写源码、测试命令、文件检索）不做领域判定，避免正常工作被拦截。

## 5. 锁定模式开关
| 开关 | 行为 |
|---|---|
| 开启（默认） | 持续定向约束+跨域拦截；不会因为闲聊自动切回通用 |
| 关闭 | 仅注入引导文案，不硬拦截；连续N次偏离后自动切回通用，附带撤销提示 |

## 6. 和 AutoConsent 的关系
dsh-autoconsent 的审批权限高于本插件，二者互不替代：
- 本插件：运行在AutoConsent之后，只做**收窄**，被聚焦拦截的调用不会走到审批链路；不监听审批请求、不替用户做放行决定
- AutoConsent：负责审批弹窗、自动放行逻辑，优先级更高

> 聚焦约束**不会绕过、覆盖DSH原有安全审批流程**

## 7. 默认配置（cordis.patch.yml）
| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关：关闭后不再注入引导、不拦截 |
| `enforce` | `true` | 拦截开关：关闭后仅软引导，不做硬拦截 |
| `confirmSubsidiary` | `false` | 附属弹窗确认初始值，会话可修改 |
| `defaultMode` | `general` | 新会话默认模式 |
| `lockByDefault` | `true` | 锁定模式默认开启 |
| `offTopicRevertAfter` | `3` | 未锁定时，连续偏离次数；0=关闭自动回退 |
| `idleRevertMinutes` | `0` | 空闲超时回退；0=关闭 |
| `sectionOrder` | `520` | 引导分节排序位置 |
| `pollMs` | `15000` | 面板轮询间隔（ms） |
| `sweepSeconds` | `30` | Host巡检间隔 |
| `persist` / `storageFile` | `true` / `~/.dsh/storages/focus-mode/state.json` | 会话状态持久化 |
| `retentionDays` | `30` | 本地状态保留天数 |
| `defaultPanelOpen` | `false` | 面板默认收起 |

## 8. HTTP 接口（供二次开发、诊断）
| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/dsh-focus-mode/state?session=<id>` | 会话状态、模式信息、诊断字段 |
| POST | `/dsh-focus-mode/mode` `{session, mode}` | 切换任务域 |
| POST | `/dsh-focus-mode/lock` `{session, lock}` | 锁定/解锁 |
| POST | `/dsh-focus-mode/confirm` `{session, confirm}` | 修改附属弹窗开关 |
| POST | `/dsh-focus-mode/reset` `{session}` | 重置为通用模式 |
| POST | `/dsh-focus-mode/dismiss` `{session}` | 关闭自动回退提示 |

诊断返回示例：
```json
{
  "section": { "name": "focus-mode:policy", "order": 520, "registered": true },
  "lastRender": { "result": "injected", "sessionId": "…", "mode": "data", "chars": 1100 },
  "lastGate": { "verdict": "cross-domain", "tool": "write", "domain": "ppt" },
  "stateEntries": 3
}
```

## 9. 安装方式

### 方式 1：社区索引一键安装（推荐普通用户）

DSH 插件面板，添加社区索引源，搜索 `dsh-focus-mode` 直接安装。

### 方式 2：命令行安装

```
dsh plugin --profile web add github:mxxz11/dsh-focus-mode
```

### 方式 3：本地开发链接安装（开发者）

1. 在 profile 的 package.json 添加依赖

```
{
  "dependencies": {
    "dsh-focus-mode": "link:D:/deep seek workplace/plugins/dsh-focus-mode"
  },
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-focus-mode"]
    }
  }
}
```

2. profile 目录执行 `pnpm install`，重启 DSH Host

> 
> Host 代码改动：重启 DSH；前端面板改动：刷新页面即可生效

## 12. 已知限制

- 无法 100% 精准识别隐蔽跨域，混合复杂需求建议切通用模式
- 中途切换模式，不会改写历史对话，约束从下一轮模型调用生效
- 子 Agent 是独立会话，子 Agent 不会自动继承父会话聚焦模式
- 附属动作按次判定，多条附属产物会逐个校验，开启确认开关则逐个弹窗
